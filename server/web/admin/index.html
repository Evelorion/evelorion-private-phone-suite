创建第一个管理员

这台服务器还没有管理员。创建之后这个入口会永久关闭。

以后再加管理员只能在服务器上跑 npm run admin:create <用户名>。 这样即使后台被人登进去，也没法悄悄加一个新管理员。

管理后台

管理账号、邀请码和服务器状态。

管理员看不到任何联系人内容。服务器上只有密文，解密密钥只存在用户的主口令里。 这里能看到的是元数据：账号名、记录条数、占用空间、设备活跃时间。
