这个开关保护什么？（点开）
这套系统是零知识的：服务器只有密文，解密靠你的主口令。所以两步验证保护的是 服务器账号 —— 谁能拉取密文、删除数据、看到「你有多少条联系人、 什么时候同步的」这类元数据。

它不是加密本身。拿到你主口令的人仍然能解开他已经拿到手的密文， 只是没法再从服务器拉新的。真正保护数据内容的只有主口令。

备用码
验证器或通行密钥不可用时使用，每个只能用一次。只显示这一次 —— 服务器上存的是哈希，找不回来。

通行密钥
指纹、面容、系统 PIN 或硬件密钥。比验证码更抗钓鱼
两种都要验证
默认通过其中一种即可

修改主口令

只会重新包裹密钥，服务器上的联系人一条都不用重传。恢复码保持不变。

注销账号

删除服务器上的全部密文，不可恢复。手机上已有的联系人不受影响。
